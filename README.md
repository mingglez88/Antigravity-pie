# Antigravity 启动与汉化管理工具 (Antigravity Launcher)

专为 **Google Antigravity 2.0 桌面端** 定制的可视化启动器与汉化管理平台，集成了**网络代理可视化切换**与**零误报动态内存汉化注入**能力。

---

## 一、 项目背景与解决的痛点

1. **网络代理管理痛点**：
   * 原生直接向 Antigravity 传递 `--proxy-server` 会导致其内部 loopback 通信（连接自身动态端口的 Language Server）被代理劫持，引发 `ERR_TIMED_OUT` 并导致主窗口白屏。
   * 本启动器严格遵循最佳实践，通过隔离的环境变量（`HTTP_PROXY` / `HTTPS_PROXY` / `NO_PROXY`）精确只对应用外部网络请求（模型调用、登录校验、更新检测）生效，保证主窗口毫秒级秒开。
2. **杀毒软件（火绒）误报痛点**：
   * 社区上部分预编译 Go 二进制工具由于调用隐藏控制台 API、挂载调试端口和跨进程脚本注入，极易被火绒等杀毒软件误判为 `HEUR:Backdoor/CobaltStrike` 拦截。
   * 本项目**完全摒弃第三方黑盒编译二进制**，全部采用**全透明 Python 源码与标准 CDP 协议**实现，无任何免杀风险，火绒/安全卫士零误报。
3. **版本更新不失效**：
   * 采用 Chrome DevTools Protocol 动态注入，不破坏官方 `app.asar` 资源包。官方后台自动更新后依然能正常使用，无需担心安装包损坏。

---

## 二、 核心功能

* **🚀 一键启动**：一键调用 `Antigravity.exe` 并注入环境配置。
* **🌐 代理可视化编辑与切换**：
  * 支持下拉快速切换常用本地代理（如 `http://127.0.0.1:60808`、`http://127.0.0.1:7891`、直连等）。
  * 支持添加、编辑、删除自定义代理地址。
  * 内置 **⚡ 代理连通性与网络延迟测试** 功能，一键验证节点可用性。
* **🇨🇳 动态汉化选项开关**：
  * 集成来源于 `yuexps/Antigravity-Hans` 社区经过多轮校对的完整汉化词库（2000+ 词条，支持 DOM MutationObserver 动态更新）。
  * 可在启动前自由勾选或取消“是否启用界面汉化”。
* **🔄 进程重启管理**：支持一键结束后台已有实例并以全新参数干净重启。
* **📌 一键生成桌面快捷方式**：支持一键在当前 Windows 桌面生成一键启动批处理脚本。
* **💾 配置持久化**：所有的代理列表、上次选中的代理、汉化开关、应用路径均自动保存在本地 `config.json` 中。

## 三、 目录结构

```text
antigravity-launcher/
├── assets/
│   └── antigravity-hans-overlay.js  # 完整汉化脚本与多语言词条库
├── core/
│   ├── app_launcher.py              # 进程拉起、环境变量设置与进程管理
│   ├── cdp_injector.py              # Python 原生实现的 CDP 动态注入器
│   ├── config_manager.py            # config.json 读写与默认配置管理
│   └── proxy_checker.py             # 代理端口连通性与 HTTP 网络测试
├── ui/
│   └── main_window.py               # 基于 Tkinter 的可视化主窗口
├── launcher.py                      # 统一程序入口 (支持 GUI 模式与静默模式)
├── run.bat                          # Windows 双击运行批处理脚本
├── config.json                      # 运行时自动生成的本地配置文件
└── README.md                        # 使用文档说明
```

## 四、 使用方法

### 方式 1：双击运行（最简便）
直接在资源管理器中双击根目录下的 **`run.bat`**。

### 方式 2：命令行启动
```bash
python launcher.py
```

### 方式 3：静默一键启动（桌面快捷方式）
通过主界面底部的 **【📌 生成桌面快捷方式】** 按钮在桌面生成快捷入口，后续双击即可直接按保存好的配置启动应用。
